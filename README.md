# 📐 EasyMath

**EasyMath** — 10-сынып оқушыларын Сыртқы Емтиханға (МЭСК) дайындауға арналған заманауи, интерактивті веб-сайт.

---

## ✨ Ерекшеліктері (Features)

* **🌐 Көптілділік (Bilingual):** Қазақ және орыс тілдері арасында тез ауысу мүмкіндігі (i18n).
* **📱 Адаптивті дизайн:** Мобильді құрылғыларға, планшеттерге және компьютерлерге толықтай икемделген.
* **⚡ Интерактивті элементтер:** SVG-графика, динамикалық демо-сабақ блогы және курс тарифтерін таңдау жүйесі.
* **📲 WhatsApp интеграциясы:** Оқушылар сайт арқылы тікелей менеджермен байланыса алады.

---

## 🛠 Технологиялар (Tech Stack)

* **HTML5** — Семантикалық құрылым
* **CSS3** — Custom Styles & Flexbox/Grid
* **JavaScript (ES6+)** — Тіл ауыстыру және интерактив логикасы
